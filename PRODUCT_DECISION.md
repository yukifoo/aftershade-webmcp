## Shortlist

### Aftershade

Specific, visual, and credible. Residents and planners encode lived knowledge that a model cannot infer; an agent searches a combinatorial set of cooling interventions. Revision-aware tools make human interruption a first-class part of the protocol rather than a staged demo.

### Civic Loom

Slightly stronger pure complementarity, but public-budget allocation easily reads as a conventional optimizer and needs more explanation before the visual payoff lands.

### Witness Map

Highly novel and tool-composable, but evidence provenance, defamation risk, and trust semantics would be difficult to make responsible and complete inside the remaining window.

## Decision

**Build Aftershade.**

> **Aftershade is an urban heat adaptation co-design lab where residents protect lived priorities while agents explore and simulate street redesigns, using WebMCP to negotiate over the same revisioned neighborhood state.**

### Human strengths

- Lived knowledge: which shortcut is used, which loading bay cannot move, where an elder rests.
- Value judgment: what must be protected, which trade-off feels acceptable, and when a plan is ready.
- Direct spatial intuition: selecting places and correcting proposals on the map.

### Agent strengths

- Search across many intervention/location combinations.
- Compose semantic operations, check constraints, simulate outcomes, and compare branches.
- Detect a human revision, re-inspect, and adapt instead of overwriting it.

### Shared application role

- Holds one legible, revisioned neighborhood state.
- Makes proposals, simulations, authorship, constraint failures, and history visible.
- Keeps exploration reversible through plan branches and undo.
- Exposes semantic operations to the agent and a spatial map to the human.

## Magic moment

1. Human asks the agent to create two heat-relief plans under a fixed budget while preserving the market loading bay and community garden.
2. Agent discovers Aftershade's tools, inspects the live neighborhood, creates branches, places interventions, and simulates both.
3. The map visibly changes and the comparison panel exposes trade-offs.
4. Human directly protects the library plaza and removes a canopy from one branch.
5. The revision changes. A stale agent write is rejected rather than overwriting the human.
6. Agent re-inspects, adapts the selected branch, simulates again, and presents the improved result for human commitment.

## Novelty check

Products such as UrbanSim and Digital Blue Foam model and rank urban scenarios; StreetSmart gathers resident observations for street design. Aftershade does not claim a more accurate digital twin. Its new thesis is a **negotiable simulation surface**: a person's lived constraints and an external agent's structured search meet in the same visible, revisioned page, and either party can interrupt without losing authorship or control.

WebMCP is the enabling boundary, not a chat veneer: tools are discovered only while the shared world is open; they read the current state, reject stale writes, mutate the same map the person edits, and return simulation evidence the person can inspect. Removing WebMCP removes the independent agent as a first-class co-editor and collapses the product into a small manual scenario toy.

## Scope decision

MUST SHIP: seeded neighborhood, direct human edits, branches, deterministic simulation, revision-aware imperative WebMCP tools, visible activity trail, persistence, undo/reset, production URL, production WebMCP validation, public repo/license, submission package.

SHOULD SHIP: polished plan comparison, keyboard accessibility, one natural-language judge prompt, deterministic demo path.

CUT IF NEEDED: accounts, real GIS, external weather feeds, multi-user sync, generative images, backend database, generalized scenario authoring.
